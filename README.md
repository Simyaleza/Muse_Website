# Muse Website

This website is being created for a restaurant. It is a responsive, multi-page website designed to showcase the restaurant's menu, gallery, and allow customers to make bookings and enquiries.

## Features
- Responsive design for mobile, tablet, and desktop.
- Interactive menu with a real-time search function.
- Form validation with simulated AJAX submission for the Enquiry page.
- Integrated Google Maps on the Contact page.
- SEO optimized (Meta tags, Sitemap, Robots.txt).

## Pages Included
- `index.html` (Home)
- `pages/about.html` (About Us)
- `pages/menu.html` (Menu)
- `pages/gallery.html` (Gallery)
- `pages/contact.html` (Contact Us)
- `pages/enquiry.html` (Enquiry)
- `pages/book.html` (Book Now)
